# Landing Page Personal - Samantha Mohedano Barrena

Este proyecto es una **landing page personal** desarrollada como trabajo para la asignatura **Lenguajes de Marcas**.

## 🌐 Enlace al proyecto

[Ver página en GitHub Pages](https://samanthamb.github.io/Landing_Page/)

---

## 📄 Descripción

La web tiene como objetivo simular un sitio profesional que sirva como carta de presentación digital. Está organizada en varias secciones:

- **Quién soy**: breve introducción personal.
- **CV**: currículum vitae con formación, experiencia, habilidades e idiomas.
- **Proyectos**: muestra de trabajos o desarrollos destacados.
- **Contacto**: formulario para que otros usuarios puedan contactar.

---

## 🛠️ Tecnologías utilizadas

- **HTML** – para la estructura semántica del contenido.
- **CSS** – para los estilos, diseño visual y comportamiento responsive.
- **Ionicons** – librería de iconos para mejorar la estética.
- **Google Fonts** – para el uso de tipografías personalizadas.
- **Git** y **GitHub** – para control de versiones y alojamiento del repositorio.
- **GitHub Pages** – para la publicación gratuita del sitio web.

---

## 🎯 Funcionalidades principales

- Navegación clara mediante una barra de menú.
- Formulario de contacto funcional (estructura, sin backend).
- Estilo visual atractivo mediante colores personalizados, sombras y efectos hover.
- Estructura modular de páginas HTML enlazadas.
- Se ha intentado que el diseño sea responsive adaptado a dispositivos pequeños (≤576px) y medianos (≤992px).

---

## 📌 Notas

- Este proyecto sólo utiliza HTML y CSS no se ha utilizazo JavaScript
- Se ha diseñado con un enfoque educativo, por lo que ciertos elementos como el formulario no están conectados a un backend real.
- Las imágenes utilizadas son de uso libre o creadas por la autora.
